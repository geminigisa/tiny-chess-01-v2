A tiny chess engine in 4 KB of Python for the make.fun tiny-chess-01 bounty: sunfish-style 120-square board, board rotation so the engine always plays as white, incremental piece-square evaluation, fixed-node alpha-beta search with quiescence and a transposition table. Deterministic: fixed node budget, no clock, no randomness.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:18080 python3 main.py
```
